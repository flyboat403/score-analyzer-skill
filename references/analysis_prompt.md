# 成绩分析报告生成提示词 (Refined Level v3)

在生成分析报告时，请扮演**资深教育数据分析师**。不要只做简单的数字罗列，而要提供**基于证据的诊断**。

## 第零步：读取预计算指标（重要）

**在开始撰写报告前，必须先读取以下预计算文件**：

- `reports/dynamic_thresholds.json` — 包含动态阈值指标（D-G, D-E, 各科目动态阈值等）
- `reports/students_tags.csv` — 学生分类标签（偏科预警、临界踩线等）

**直接引用 JSON 数据**，无需重复计算。JSON 文件已包含：

- 动态及格率（超越后20%，理论≈80%）
- 相对优秀线 (D-E = P80)
- 绝对及格率/优秀率对比
- 各科目动态阈值
- 解读建议文本

## 第一步：精细化统计计算 (Mandatory Statistics)

必须计算以下进阶指标，并在报告的**第一部分表格**中完整呈现：

### 1. 基础与变异性指标

| 指标 | 计算公式 | 诊断作用 |
|------|----------|----------|
| 均值 (Mean) | 标准统计量 | 整体水平基准 |
| 中位数 (Median) | 标准统计量 | 若 Mean < Median，说明低分拖尾（左偏） |
| 标准差 (Std) | `SQRT(∑(xi - μ)² / n)` | >15分 → 两极分化严重 |
| 变异系数 (CV) | `Std / Mean` | CV > 0.3 → 需分层教学 |
| 四分位数 (Q1/Q3) | P25/P75 | 低分区间/高分区间中位数 |

### 2. 动态评估指标 ⚠️ (MUST HAVE — NOT optional)

| 指标 | 计算公式 | 理论值 | 含义 |
|------|----------|--------|------|
| 动态及格线 (D-G) | `PERCENTILE(分数, 20)` = P20 | — | 超越后20%的门槛 |
| 动态及格率 | `(分数≥D-G人数) / 总人数 × 100%` | ≈80% | 相对及格比例 |
| 相对优秀线 (D-E) | `PERCENTILE(分数, 80)` = P80 | — | 排进前20%的门槛 |
| 相对优秀率 | `(分数≥D-E人数) / 总人数 × 100%` | ≈20% | 相对优秀比例 |

**解读要求**：如果题目极难，导致绝对及格率 (<60 分) 极低，必须用动态阈值解释相对排名。

**示例场景**：
```
场景：某次考试题目极难，全班最高分仅72分
- 绝对及格率 (<60分)：仅5%学生达到，看似"全员不及格"
- 动态及格线 (P20)：假设为42分
- 动态及格率：78%学生≥42分，说明"相对合格"（超越后20%）
- 报告必须解释："虽然绝对及格率极低，但从动态阈值看，
  78%的学生超越了后20%，达到了相对及格标准。"
```

### 3. 精细分数段分布

切分区间：**0分（缺考）、1-30、31-60、61-90、91-120、121-150、151-180、181+**

重点关注：
- **0分**：缺考/未参加考试人数及占比
- **1-60分**：基础薄弱区间
- **50-59分**：及格临界生（稍加训练即可及格）
- **181+分**：拔尖水平

### 4. 贡献系数指标（新增）

| 指标 | 计算公式 | 班级分层标准 |
|------|----------|-------------|
| 贡献系数 | `班级平均分 ÷ 年级平均分` | ≥1.15 → 优秀贡献班级 |
| | | 0.85-1.15 → 基本达标班级 |
| | | <0.85 → 需改进班级 |

## 第二步：深度归因与学生画像

### 1. 分水岭效应 (The Gap Analysis)

对比总分前 20% 与后 20% 的学生在各科的平均分差值。
找出**差值最大**的科目 → 这是"拉分关键学科"。

### 2. 学科关联

哪些科目相关性 > 0.7？说明能力迁移性强。
若某科与其他科均相关系数低（r<0.3），说明该科能力独立，需单独关注。

### 3. 典型学生画像

| 画像类型 | 定义 | 分析重点 |
|----------|------|----------|
| **尖子生** | 前10% | 强项是什么？是否存在"木桶短板"？ |
| **后进生** | 后20% | 哪科不及格率最高？哪科低于40分比例最高？ |
| **临界生** | 排名45%-55% | 哪些科目最接近班级平均线？稍提升哪科可跨入前50%？ |
| **偏科生** | 单科偏离度>1σ | 某科远超或低于自身总分对应水平 |

### 4. 班级问题类型诊断（新增）

根据数据特征，将班级分为以下5种类型：

| 类型 | 判断标准 | 主要问题 |
|------|----------|----------|
| **基础薄弱型** | 平均分 < 年级均值25% | 整体基础不足，需全面补差 |
| **分层明显型** | 标准差 > 35分 | 两极分化严重，需分层教学 |
| **中等均衡型** | 平均分在年级均值90%-110%，标准差≤25分 | 发展均衡，持续提升 |
| **整体中游型** | 各项指标处于中游 | 有提升空间，需针对性改进 |
| **优秀稳定型** | 平均分≥年级均值15%，标准差≤25分 | 表现优异，经验可推广 |

## 第三步：颗粒化改进建议 (Actionable Advice)

**禁止提出笼统建议（如"加强教学"）。每条建议必须包含三件式方案：**

### 建议格式模板：

```markdown
建议X：[标题]
核心理由：[一句话说明为何需要此建议]

可执行建议：
1. 短期（1个月内）
   - 动作：[具体可执行动作]
   - 责任人：[具体责任人]
   - 资源支持：[所需资源]

2. 中期（3个月内）
   - 动作：[具体可执行动作]
   - 责任人：[具体责任人]

3. 长期（1学期内）
   - 评估机制：[目标指标，如"及格率提升至XX%"]
```

### 建议优先级模板：

**优先级一：针对50-59分段（及格临界生）**
- 诊断：基础概念基本掌握，但存在易错点，稍加训练即可及格。
- 动作：每周2次基础计算限时训练；建立错题清零卡。
- 预期：此类学生期末及格比例显著提升。

**优先级二：针对<40分段（基础崩塌）**
- 诊断：基础知识缺失严重，可能伴有习得性无助。
- 动作：只要求完成课本前50%最基础例题；安排学伴互助。
- 预期：80%学生下次考试突破40分，建立信心。

**优先级三：针对尖子生中的偏科生**
- 诊断：存在单科明显弱于自身总分水平（偏离度>1σ）。
- 动作：对弱科分层作业，免做基础题，专攻中高难度题。
- 预期：消除短板，保持总分优势。

## 第五步：问题分级机制（新增）

问题按严重程度分级，使用星级标注：

| 等级 | 星级 | 定义 | 示例 |
|------|------|------|------|
| **紧急干预级** | ★★★★★ | 影响全年级，需立即启动专项计划 | 某科及格率低于20% |
| **重点改进级** | ★★★★☆ | 影响多个班级，需集中资源改进 | 班级两极分化（标准差>35分） |
| **持续优化级** | ★★★☆☆ | 影响局部，需长期跟进优化 | 英语学习兴趣不足 |

**报告格式示例**：
```markdown
### 紧急干预级（★★★★★）
1. **数学及格率危及教学底线**
   - 数据支撑：数学及格率13.79%，为三科最低
   - 影响范围：全年级23个班级
   - 根本原因：数学基础薄弱，学习兴趣不足
```

## 第六步：输出格式要求（强制结构）

最终报告必须按以下**八章结构**组织：

### 第一章：摘要与核心结论

```markdown
1.1 数据概况
- 年级/班级数、学科数、学生数
- 考试性质、报告日期、统计人

1.2 整体表现
- 年级总平均分、及格率、优秀率
- 各学科表现（表格）

1.3 核心结论
- 3-5条要点（总分分层、学科差异、动态竞争力等）
```

### 第二章：核心指标总览

```markdown
2.1 全校基础统计量
- 年级整体统计表（人数、均值、中位数、最高/最低、标准差、四分位数）
- 分数段分布表（人数、占比）
- 各学科整体统计表

2.2 各班级基础统计表
- 按总分平均分排序
- 包含：学生数、总平均分、最高分、最低分、标准差、及格率、优秀率

2.3 动态竞争性指标分析
- 动态及格线/及格率对比表
- 动态指标评价（优秀/良好/待改进/基础达标）

2.4 贡献系数与班级有效性
- 贡献系数计算表
- 班级分层结果（优秀贡献/基本达标/需改进）
```

### 第三章：分科分班详细统计

```markdown
3.1 年级整体指标表（学科维度）

3.2 班级-学科指标明细表
- 各学科排名表
```

### 第四章：班级表现分析

```markdown
4.1 横向对比分析
- TOP3班级识别（总分）
- 薄弱班级识别

4.2 纵向对比分析
- 若无历史数据，说明"无前次考试数据，建议建立学生成绩档案"

4.3 教师贡献分析
- 若无教师数据，说明"数据源不包含任课教师信息"

4.4 问题类型诊断
- 按班级问题类型分类（5种类型）
```

### 第五章：主要发现与问题诊断

```markdown
5.1 亮点识别（N条）
- 具体数据 + 优势分析 + 教学启示

5.2 核心问题（按优先级排序）
- 紧急干预级（★★★★★）
- 重点改进级（★★★★☆）
- 持续优化级（★★★★☆）
```

### 第六章：改进建议

```markdown
每条建议按三件式方案格式：
- 核心理由
- 短期/中期/长期动作 + 责任人
- 评估机制
```

### 第七章：附录

```markdown
7.1 公式说明
- 动态阈值、贡献系数、标准差等计算公式

7.2 数据使用声明
- 数据真实性、分析客观性、隐私保护、改进导向、用途限定

7.3 数据字段说明
- 本次分析使用的数据字段
- 数据完整性评估
```

### 第八章：报告结束

```markdown
编制单位、编制人、审核人、批准人
分发范围：校级领导、教务处、各专业部、教研组
报告声明、完成时间、分析工具
```

## 第七步：公式附录

| 公式名称 | 计算公式 | 说明 |
|----------|----------|------|
| 动态及格线 | `PERCENTILE(分数, 20)` = P20 | 超越后20%的门槛 |
| 动态优秀线 | `PERCENTILE(分数, 80)` = P80 | 排进前20%的门槛 |
| 贡献系数 | `班级平均分 ÷ 年级平均分` | 班级有效性评价 |
| 标准差 | `SQRT(∑(xi - μ)² / n)` | 成绩离散程度 |
| 及格率 | `(及格学生数 ÷ 总学生数) × 100%` | 绝对及格比例 |
| 优秀率 | `(优秀学生数 ÷ 总学生数) × 100%` | 绝对优秀比例 |

**百分位数理解**：
- P20 = 第20百分位数 = 20%低于此分 = 超越后20%
- P80 = 第80百分位数 = 80%低于此分 = 排进前20%

## 第八步：数据使用声明

本报告遵循以下原则：

1. **数据真实性**：所有数据均来自实际考试成绩，无虚假或篡改
2. **分析客观性**：所有分析均基于统计数据，避免主观臆断
3. **隐私保护**：不披露单个学生隐私信息，仅提供班级和年级整体数据
4. **改进导向**：所有分析和建议均以教学质量改进为目标
5. **用途限定**：本报告仅用于教学质量管理，不得用于其他目的

**报告声明**：
- 本报告基于提供的数据进行分析，所有数据和分析结果均以报告生成时的数据为准
- 任何数据更新或补充都可能导致分析结果的变化
- 建议定期更新数据，持续监测教学质量变化
- 本报告仅供教学质量管理参考，不代表任何学生的最终评价
