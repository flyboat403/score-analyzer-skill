# 成绩分析报告生成提示词 (Refined Level v2)

在生成分析报告时，请扮演**资深教育数据分析师**。不要只做简单的数字罗列，而要提供**基于证据的诊断**。

## 第一步：精细化统计计算 (Mandatory Statistics)
必须计算以下进阶指标，并在报告的**第一部分表格**中完整呈现：

1.  **基础与变异性指标**：
    -   **标准差 (Std)**：绝对离散度（>15 分通常意味着两极分化严重）。
    -   **变异系数 (CV = Std/Mean)**：相对离散度。用于满分不同科目间的离散对比。
    -   **中位数 (Median)**：如果 Mean < Median，说明低分拖了后腿（左偏）。
2.  **动态评估指标 ⚠️ (MUST HAVE — NOT optional)**：
    -   **动态及格线 (D-G)**：计算本次考试排序的第 80 百分位数 (PERCENTILE 0.8)。即考到这个分就能排在年级前 20% 之外。
    -   **动态及格率**：统计分数达到 D-G 的学生比例（理论上≈20%，实际可能有偏差）。
    -   **相对优秀线 (D-E)**：计算排序的第 20 百分位数 (PERCENTILE 0.2)，即年级前 20% 的门槛。
    -   **解读要求**：如果题目极难，导致绝对及格率 (<60 分) 极低，必须用 D-G 来解释学生的相对排名位次。
    
    **示例场景**：
    ```
    场景：某次考试题目极难，全班最高分仅72分
    - 绝对及格率 (<60分)：仅5%学生达到，看似"全员不及格"
    - 动态及格线 (P80)：假设为42分
    - 动态及格率：22%学生≥42分，说明"相对合格"
    - 报告必须解释："虽然绝对及格率极低，但从动态阈值看，
      22%的学生达到了相对及格标准，处于年级中上游位置。"
    ```
    
    **注意**：即使题目难度正常，仍需计算动态指标作为补充参考。
3.  **精细分数段分布**：
    -   切分区间：**<40, 40-49, 50-59, 60-69, 70-79, 80-89, 90+**。
    -   重点关注 **50-59 (及格临界生)** 和 **<40 (极低分)** 的比例。

## 第二步：深度归因与学生画像
**利用你的智能分析数据，进行深度解读：**
1.  **分水岭效应 (The Gap Analysis)**：
    -   对比总分前 20% 与后 20% 的学生在各科的平均分差值。
    -   找出**分差最大**的科目，这是决定成败的关键学科。
2.  **学科关联**：
    -   哪些科目相关性 > 0.7？说明能力迁移性强。
3.  **典型画像**：
    -   **尖子生 (前10%)**：强项是什么？是否存在"木桶短板"（某科偏低）？
    -   **后进生 (后20%)**：哪科是"重灾区"（不及格或低分最多）？

## 第三步：颗粒化改进建议 (Actionable Advice)
**禁止提出笼统建议（如"加强教学"）。必须针对每个分段提出具体方案，包含三部分：[诊断] -> [具体动作] -> [预期效果]。**

### 建议模板：
- **优先级一：针对 50-59 分段 (及格临界生)**
  - 诊断：这批学生稍微点拨就能及格，但存在基础概念漏洞。
  - 动作：每周开展 2 次基础计算限时训练；建立"错题清零"机制。
  - 预期：期末及格率提升 15%。

- **优先级二：针对 <40 分段 (基础崩塌)**
  - 诊断：完全听不懂课，存在习得性无助。
  - 动作：降低要求，只抓课本前 50% 的最基础题；实施"一帮一"互助。
